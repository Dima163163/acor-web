# Визуальный аудит и доработка — 10 сентября 2026

## Наблюдения

1. Очень плотный трекинг крупных заголовков ухудшал читаемость кириллицы. На первом экране скульптура занимала слишком много высоты на ноутбуке.
2. Превью проектов давали сильное первое впечатление, но не позволяли рассмотреть изображение без перехода на другую страницу.
3. Статичный процесс работы не раскрывал, что получает клиент на каждом этапе.
4. На длинной главной странице было неудобно возвращаться между разделами.

## Что изменено

- Ослаблен отрицательный трекинг, увеличен ряд поясняющих подписей, скорректированы размеры первого экрана и скульптуры для ноутбуков и телефонов.
- На главной и в портфолио добавлена отдельная кнопка полноэкранного просмотра. Галерея поддерживает кнопки, стрелки клавиатуры, горизонтальный свайп и Escape. Перелистываются только проекты текущего фильтра. Основная ссылка карточки по-прежнему открывает подробный кейс.
- Процесс работы превращён в три переключаемых этапа с оригинальными схемами структуры, дизайн-системы и выпуска продукта. Каждый этап показывает конкретный результат для клиента. Поддержаны клавиатурные стрелки, Home/End и режим без анимации. Без JavaScript все этапы видны последовательно.
- Добавлена компактная навигация по разделам главной с выделением текущего раздела и возвратом наверх. Она появляется после первого экрана и скрывается у подвала, кроме случая, когда внутри неё находится клавиатурный фокус.
- Переходы галереи и этапов используют короткие анимации по действию пользователя; постоянный цикл JavaScript не добавлен. Глобальный переключатель и системное уменьшение движения сохранены.
- Форма получила рабочий статический сценарий: исправленный бюджет, открытие готового письма через `mailto`, защита от двойного клика и отдельное локальное скачивание `.txt`.
- В Lab добавлены пресеты материала и формы, копирование текущих параметров, а у кейсов появилась цепочка `Проекты / название / Решение`. Состояние фильтров команды и портфолио сохраняется в URL.
- Карта погружения переведена на трёхколоночную сетку: горизонтальный коннектор теперь проходит между центрами всех трёх узлов, а вертикальные линии совпадают с ними на одной базовой линии.
- Возврат к началу страницы теперь плавный; системное `prefers-reduced-motion` по-прежнему отключает плавное движение.

- На контактах добавлен пошаговый Brief Builder: четыре вопроса собирают тип проекта, аудиторию, цель и ощущение, а резюме синхронизируется с URL и существующей формой.
- В кейсах появились контекстные карточки, интерактивное сравнение черновой структуры с собранной формой и таймлайн решений. На странице студии добавлен раскрывающийся мини-журнал.
- Команду можно фильтровать по роли в проекте (`исследует`, `проектирует`, `разрабатывает`, `проверяет`, `ведёт`). Lab получил палитры, случайную форму и сохранение палитры в URL.
- Командная палитра открывается по `⌘K` / `Ctrl+K`, фильтрует разделы и закрывается кнопкой или Escape.
- На странице услуг добавлена секция прозрачности с форматами работы, коммуникацией и примером стека. Кнопки CTA получили лёгкий магнитный отклик только для fine pointer.
- В ветке `codex/studio-v2-polish` добавлена ночная цветовая атмосфера без перестройки макета. Переключатель доступен в шапке, выбор сохраняется в `localStorage`, цвет браузерного UI обновляется через `theme-color`.
- Для указателя на десктопе добавлен мягкий spotlight-градиент. Он появляется только рядом с интерактивными элементами и полностью отключается в режиме без движения.
- Черновик контактной формы сохраняется в `sessionStorage` и восстанавливается после возврата на страницу. На кейсах появилась share-кнопка: используется системное меню, а при его отсутствии ссылка копируется в буфер обмена.
- Портфолио получило переключатель сетка/список, сортировку по названию и локальные закладки. В услугах появился ориентир по типу проекта, глубине участия и темпу, а также раскрывающийся FAQ.
- Добавлены крошки на внутренних страницах, печатная версия кейсов, PWA-manifest, network-first service worker с офлайн-экраном и локальные события `acor:interaction`, которые можно подключить к аналитике позже без сетевой отправки.
- Добавлены отдельная страница конфиденциальности, 404-сценарий, `robots.txt` и sitemap. Прогресс чтения теперь доступен как ARIA progressbar, а при потере сети появляется понятное локальное уведомление.
- На главной появился горизонтальный marquee с ключевыми направлениями студии и нейтральный online-индикатор в шапке. Marquee отключается вместе с остальными эффектами при `prefers-reduced-motion` или ручном выключении анимации.
- Для внутренних страниц добавлен короткий ориентир по времени чтения. В браузерах с поддержкой View Transitions API переход между страницами получает короткий cross-fade без вмешательства в навигацию.

## Проверка

- 10 страниц × 3 ширины: 320, 768, 1280 px — горизонтального переполнения нет.
- Визуально проверены первый экран, галерея и этапы на компьютере и телефоне.
- Проверены клавиатурное перелистывание галереи, Escape, возврат фокуса, отсутствие повторяющихся SVG ID и галерея с одним отфильтрованным проектом.
- Проверены переключение этапов с клавиатуры, состояния ARIA и режим без анимации, возврат наверх и скрытие локальной навигации.
- Проверка runtime выполняется сборкой Vite и TypeScript-проверкой: `npm run typecheck`, `npm run build`. Ошибок в консоли браузера при проверке не обнаружено.

Это локальная версия сайта. Существующие демонстрационные проекты и вымышленные профили команды сохраняют свои обозначения; отправка брифа на сервер не подключена.
