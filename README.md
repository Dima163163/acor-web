# Acor Web — Form & Focus

Светлый сайт digital-студии: крупная типографика, кобальтовый акцент, скульптурный знак и проекты как отдельные визуальные сцены.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://127.0.0.1:5173. Production-проверка: `npm run typecheck`, `npm run build`, `npm run preview`.

## Архитектура

Приложение собрано на Vite и React Router 7. В корне остаётся один `index.html` как HTML-shell; маршруты, шапка и футер живут в React/FSD-слоях:

- `src/app` — точка входа, BrowserRouter и мост legacy-интерактивов;
- `src/pages` — содержимое экранов маршрутов;
- `src/widgets` — общие React-виджеты шапки и футера;
- `src/shared` — навигация, SEO-метаданные и типизированные настройки.

Основные URL используют чистые пути: `/`, `/cases`, `/services`, `/about`, `/team`, `/careers`, `/lab`, `/contact`, `/cases/arden`, `/cases/greenflow`, `/cases/orbit`, `/privacy`. Старые `.html`-адреса поддерживаются как алиасы внутри приложения.

Существующие сценарии (фильтры, бриф, Lab, галерея, карточки команды, локализация, тема и доступность) пока усиливаются через изолированный `script.js`. После переноса очередного интерактива его можно удалить из legacy-слоя без изменения роутинга.

## SEO и деплой

Клиентский роутер обновляет `title` и meta-описания при переходе, а Vercel переписывает чистые URL на `index.html` через `vercel.json`. Для максимальной поисковой индексации следующий шаг — добавить SSR или статический пререндер React-маршрутов: чистая SPA-версия не заменяет серверный HTML для роботов.

Service worker обновлён под единый shell и возвращает `index.html` как offline fallback. Медиа доступны через `public/assets`, поэтому пути к изображениям не зависят от хешей Vite.

## Интерактив и доступность

Появление типографики, параллакс знака, магнитный отклик CTA, раскрытие услуг, фильтры портфолио, пошаговый бриф, Lab с ползунками и случайной формой, мобильное меню с Escape и focus trap, командная палитра `⌘K` / `Ctrl+K`, View Transitions, четыре языка и `prefers-reduced-motion`.

Демонстрационные данные команды и портреты вымышлены и обозначены как материалы макета. Адрес `hello@acorweb.ru` требует проверки владельцем перед публикацией.
