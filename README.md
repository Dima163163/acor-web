# Acor Web — Form & Focus

Самостоятельный светлый дизайн digital-студии: крупная типографика, кобальтовый акцент, скульптурный знак и проекты как отдельные визуальные сцены. HTML, CSS и JavaScript без сборки и сторонних JS-библиотек.

## Просмотр

```sh
python3 -m http.server 8080 --bind 127.0.0.1
```

Открыть http://127.0.0.1:8080.

## Страницы

- `index.html` — главная
- `cases.html` — портфолио с фильтрами
- `case-arden.html`, `case-greenflow.html`, `case-orbit.html` — отдельные концепции
- `services.html` — услуги с раскрывающимися описаниями
- `about.html` — подход студии
- `team.html` — основатель и направления экспертизы
- `lab.html` — управление поворотом и масштабом графики
- `contact.html` — подготовка и скачивание брифа

Все страницы используют общие `styles.css` и `script.js`. Для обновления ресурсов без старого браузерного кеша в ссылках используется параметр версии.

## Интерактив и доступность

Появление типографики, параллакс знака по движению указателя, раскрытие услуг, подсказка на превью проекта, анимации наведения, фильтры портфолио, Lab с ползунками, меню с Escape. Есть заметный фокус, ссылка перехода к содержимому и системный `prefers-reduced-motion`. Переключатель анимации сохраняет выбор в пределах сессии. Нет перехвата прокрутки, обязательного прелоадера или постоянно работающего animation loop.

## Форма и демонстрационные данные

Бэкенд и отправка заявок не подключены. Форма создаёт локальный UTF-8 TXT-файл; данные не отправляются на сервер. Адрес `hello@acorweb.ru` перенесён из исходного проекта и требует проверки владельцем перед публикацией. Проекты обозначены как концепции, финансовые данные — демонстрационные, неподтверждённые достижения и метрики исключены. На странице команды использовано имя основателя из исходного проекта. Добавлены 24 демонстрационных профиля в семи направлениях, по 3–4 человека в каждом. Имена, описания и сгенерированные портреты явно обозначены как вымышленные. Портреты хранятся в четырёх JPEG-спрайтах, точные промпты — в `assets/TEAM-PROMPTS.md`.

## Визуальные материалы

Liqium был указан пользователем как ориентир по подаче. Его код, тексты, логотип, фотографии и кейсы не использовались. Макет, брендовый знак, тексты и взаимодействия написаны для Acor. Три изображения созданы через встроенный imagegen, промпты и пути — в `ASSETS.md`. Интерфейс Orbit собран в HTML/CSS/SVG. Шрифты Manrope и Golos Text загружаются через Google Fonts, предусмотрены системные fallback-шрифты.

## Проверка

Проверены 10 страниц на ширинах 320, 768 и 1280 px, локальные ссылки и изображения, фильтр портфолио, аккордеон услуг, мобильное меню и Escape, валидация брифа и перенос выбранной услуги. JavaScript проверен `node --check script.js`.

Исходная версия перед переделкой сохранена отдельно: `/private/tmp/acor-before-20260910/`.

## Расширение команды и интерактива

Фильтры по направлению, поиск по имени, роли и навыкам, подробные карточки сотрудников в нативном dialog с Escape и возвратом фокуса. На главной добавлен интерактивный выбор типа проекта: меняются превью, команда и ссылка на бриф. Дополнительно: фиксируемая при прокрутке навигация, индикатор чтения, движение скульптуры, раскрытие проектных сцен, параллакс и цветные портреты при наведении. Постоянные CSS-анимации приостанавливаются вне экрана; режим уменьшенного движения сохранён.
